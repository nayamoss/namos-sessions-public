# Component showcase

**Route:** `/dev/components`
**User:** Authenticated product/development staff.

## Journey

1. The user opens Components from the event settings navigation and sees the active theme surface.
2. They inspect each shared control's default, hover, focus-visible, disabled, validation, and dark/light presentation where shown.
3. They exercise styled menus/listboxes and confirm no visible product dropdown is a native browser select.
4. They test desktop and mobile widths and keyboard focus order, then navigate back to a product page.

## Success and recovery

This is intentionally read-only: CRUD is N/A. A missing component or rendering failure identifies the component and offers a safe return to Settings.
